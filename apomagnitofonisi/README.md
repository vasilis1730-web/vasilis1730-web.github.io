# Απομαγνητοφώνηση

Μετατροπή αρχείων ήχου και βίντεο σε κείμενο, με ομιλητές, χρόνους,
υπότιτλους, εξαγωγή σε Word και περίληψη ή πρακτικά.

**https://apomagnitofonisi.texnikes.app**, και εφαρμογή Android στο Google Play
(`gr.rhodes.apomagnitofonisi`).

## Τι κάνει

- **Μεταγραφή στη συσκευή**, δωρεάν και ιδιωτικά, με το Whisper (Transformers.js,
  WebGPU ή WASM). Ο ήχος δεν φεύγει από τη συσκευή.
- **Μεταγραφή στο cloud** με ElevenLabs Scribe, με δικό σας κλειδί: ταχύτερα,
  ακριβέστερα, με διαχωρισμό ομιλητών.
- **Ομιλητές, χρόνοι, διόρθωση, αναζήτηση** και αναπαραγωγή από κάθε φράση.
- **Εξαγωγή** σε Word (.docx), κείμενο (.txt), υπότιτλους (.srt, .vtt) και .json.
- **Περίληψη, πρακτικά, αποφάσεις και εκκρεμότητες** με το Claude της Anthropic, με δικό σας κλειδί.
- **Κοινοποίηση** αρχείου ήχου ή βίντεο από άλλη εφαρμογή στο Android.

Χωρίς λογαριασμό, χωρίς διαφημίσεις, χωρίς δικό μας server: μεταγραφές,
ρυθμίσεις και κλειδιά μένουν στη συσκευή του χρήστη.

Ανεξάρτητη εφαρμογή, δεν συνδέεται με κανέναν δημόσιο φορέα.

## Ανάπτυξη

```sh
npm ci --ignore-scripts
npm test               # λογική εφαρμογής και υποδομή
npm run build          # dist/
npm run test:browser   # Chromium πάνω στο dist με την πραγματική CSP
npm run preview        # http://localhost:8788
npm run icons          # εικονίδια και γραφικά καταστήματος
```

Δομή: `src/` η εφαρμογή (domain, application, infrastructure, ui), `tools/` build,
Android και έλεγχοι, `android/` η εφαρμογή Android, `tests/` οι έλεγχοι, `docs/` η
τεκμηρίωση (`DEPLOYMENT.md`, `ANDROID.md`, `PLAY.md`). Οδηγίες για αλλαγές: `CLAUDE.md`.
